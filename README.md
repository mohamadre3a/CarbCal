# CarbCal

CarbCal is a chatbot project that helps you find the estimated amount of carbohydrates in a food. The goal is to let you describe a food and its portion size, then receive an estimate of its carbs in grams using OpenAI's API.

This is an ongoing personal project. I plan to integrate it into another personal project of mine later.

## Project status

Work in progress. This repository currently contains the project documentation and environment configuration. The chatbot implementation and instructions for running it will be added as development continues.
